# UI Assets

This directory contains user interface elements like buttons, panels, and icons.

## Required Assets

### Panels (9-patch PNG recommended)
- `panel_bg.png` - Semi-transparent panel background for UI
  - Size: 64x64 minimum (will be stretched)
  - Color: Dark blue-gray (#2c3e50) with ~85% opacity
  - Border: 2-4px lighter border for definition

### Buttons
- `button_normal.png` - Button default state (e.g., 100x32)
- `button_hover.png` - Button when mouse hovers over it
- `button_pressed.png` - Button when clicked
  - Style: Slightly rounded corners, gradient, modern flat design

### Icons (16x16 pixels each)
- `icon_money.png` - Dollar sign or coin icon (gold color)
- `icon_time.png` - Clock icon (cyan/blue color)
- `icon_pause.png` - Pause symbol (two vertical bars)
- `icon_play.png` - Play symbol (triangle pointing right)
- `icon_speed_1x.png` - Normal speed indicator
- `icon_speed_2x.png` - Fast speed indicator
- `icon_speed_4x.png` - Very fast speed indicator
